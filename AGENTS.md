# Project Instructions

Read both files below before doing any work on this project:

- [.agents/CONTEXT.md](.agents/CONTEXT.md) — General explanation on the purpose of the project and its main features.
- [.agents/PYTHON-STANDARDS.md](.agents/PYTHON-STANDARDS.md) — Non-negotiable Python code quality rules

IMPORTANT: you have to use the pip package: [Temporal SDK Wrapper](https://pypi.org/project/temporal-worker-sdk/), read its documentation to understand its use and purposes and the examples of how to use it.

Both files are authoritative. The architecture defines *what* to build; the standards define *how* to build it.
